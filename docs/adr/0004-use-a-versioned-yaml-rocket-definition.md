# Use a versioned YAML rocket definition

Use a strict, versioned `rocket.yaml` document as the source of truth, with explicit SI field suffixes, Mass Properties, and discriminated Fixed Fin, All-Moving Fin, and Control-Surface Fin definitions. Preview poses and derived Barrowman results remain outside the document so saved geometry stays human-readable, auditable, and independent of a particular UI or future simulator export.
