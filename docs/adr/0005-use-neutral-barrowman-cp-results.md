# Use neutral Barrowman CP results

Calculate and expose Barrowman CP only for Neutral Geometry under the original thin, uncanted, steady, subsonic, near-zero-angle assumptions. Report the nose and each Fin Set as aerodynamic contributors, treat the constant cylindrical Body Tube as zero normal-force contribution with no standalone CP, and combine contributors by normal-force-slope-weighted moments. Deflected controls are visualized but do not trigger a claim of deflected-control aerodynamics; placing an All-Moving Fin hinge at its neutral CP station is an explicit project mechanical convention.
